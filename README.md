# Guinée Divertisity

Petite application web statique de divertissement créée par Ibrahima Bah.

Pour lancer :

1. Ouvrir `c:/Users/ibrahima bah/Documents/Portfolio/index.html` dans un navigateur web.
2. Cliquer sur les boutons pour afficher des blagues, lancer le quiz, ou jouer un son.

Fichier principaux :

- `index.html` — page principale
- `styles.css` — styles
- `app.js` — interactivité (blagues, quiz, son)
